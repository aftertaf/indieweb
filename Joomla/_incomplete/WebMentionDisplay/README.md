# Webmention Display (Content Plugin)

This Joomla 6 content plugin displays incoming Webmentions under articles.

## Features

- Shows mentions stored in `#__webmention_received`
- Filters by article ID inside the `target` URL
- Displays:
  - Webmention type
  - Source URL
  - Timestamp
- Fully Joomla 6–compatible

## Installation

1. Zip the plugin folder.
2. Install via Joomla Extension Manager.
3. Enable **Content – Webmention Display**.
